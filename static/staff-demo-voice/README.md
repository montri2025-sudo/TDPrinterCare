# Thai narration for the staff menu Demo

Same rules as `static/field-service-voice/README.md`: generated offline on the owner Mac with
`tools/make-field-service-voice.py` from the authorized reference (kept in ignored `artifacts/`).
`manifest.json` maps the exact text of each `step(...)` in `static/staff-demo.js` to an MP3.
Until generated, the Demo shows timed Thai captions (no substitute voice).
