# บริการนอกสถานที่และคู่มือแนะนำ

หน้าทำงานคือ `/field-service` ใช้ข้อมูลที่บันทึกใน PostgreSQL ตามสิทธิ์ ดู [field-service-live.md](field-service-live.md)

## ไม่มีข้อมูลตัวอย่างในเมนู

- เอาหน้าบริษัท/ใบงาน/เครื่องสมมติออกแล้ว ไม่ส่งชุดข้อมูลตัวอย่างเข้าเบราว์เซอร์
- URL เก่า `/field-service/demo` เปลี่ยนไปหน้าทำงานจริง ไม่สร้างหรือเติมตัวอย่างลงฐานข้อมูล
- ไม่มีเมนู “คู่มือทดลองใช้งาน” ที่เปิดโรงงานสมมติ
- ปุ่ม “Demo แนะนำหน้านี้” ของพนักงานยังอยู่ เป็นคู่มืออ่านอย่างเดียว ไม่กดปุ่มหรือบันทึกใบงานแทนผู้ใช้
- ไฟล์ข้อมูลสมมติที่จำเป็นต่อ unit tests อยู่ใน `tests/fixtures/` เท่านั้น ไม่ได้ COPY เข้า Docker image
- ปิดเส้นทาง Google สำหรับพิกัดสมมติเดิม ไม่ส่งข้อมูลออกบริการภายนอกจากงานนี้

## เสียงคู่มือ

ใช้เสียงต้นแบบเดิมที่เจ้าของระบบอนุญาต (เหมือนเมนูลูกค้า) สร้างออฟไลน์ด้วย
`tools/make-field-service-voice.py` → `static/staff-demo-voice/` มีคำบรรยายคงที่ 70 ข้อความ รวมคำแนะนำหน้าบริการจริง
เสียงต้นฉบับ โมเดล และไฟล์ระหว่างทำเก็บใน artifacts/ ที่ Git ไม่ติดตาม

ปุ่ม Play เริ่มคำแนะนำภาษาไทยตามหน้าที่เปิด เลื่อนต่อเมื่อพูดจบ มีพัก/เล่นต่อ ก่อนหน้า ถัดไป ปิด และ checkbox ปิดเสียง
เมื่อซ่อนแท็บจะหยุดเล่น หากเบราว์เซอร์บล็อกเสียงจะแสดงให้กดเล่นต่อ ไม่สลับใช้เสียงอื่นแทน
เมนูคู่มือหลักไม่เล่น Demo อัตโนมัติ ลำดับเมนูเดินตามสิทธิ์ของบัญชีที่ล็อกอิน

```sh
<PrintScape voice venv>/bin/python tools/make-field-service-voice.py --reference artifacts/customer-voice/reference.wav
python3 tools/check_demo_voice.py
```

ตัวสร้างเข้ารหัสต้นแบบครั้งเดียวและใช้ prompt cache เดียวกันทั้งชุด ทำต่อจากไฟล์ที่เสร็จได้โดยไม่สร้างซ้ำ
การทดสอบใหม่ตรวจความครบของทุกข้อความใน manifest จึงไม่ผ่านเมื่อมีแต่คำบรรยายและไม่มีไฟล์เสียง
